1. 이 도구와 사용자

이 도구는 YouTube 채널 @n0wst4ndup의 주인 한 사람이 자기 채널에 영상을 올리고 자기 채널의 통계를 읽는 데 쓰는 개인용 도구입니다. 이 도구는 YouTube API 서비스를 사용합니다.

2. 접근하는 정보

  • 인증 토큰: 채널 주인이 허용한 권한(영상 올리기 youtube.upload, 통계 읽기 yt-analytics.readonly)으로 Google에서 받은 토큰
  • 올리는 영상: 채널 주인이 만든 영상 파일과 제목·설명·태그
  • 채널 통계: 이 채널 영상의 조회수, 참여 조회수, 시청 시간, 평균 시청 비율, 좋아요·댓글·공유 수, 구독자 증감 같은 집계 수치

다른 사람의 계정이나 채널, 댓글 내용, 시청자 개인을 알아볼 수 있는 정보에는 접근하지 않습니다.

3. 쓰는 방식과 공유

영상을 채널에 올리고, 통계를 채널 주인의 PC에 기록해 다음 영상을 만드는 데 참고하는 데만 씁니다. 채널 주인이 쓰는 AI 도구(Anthropic의 Claude)가 이 기록을 읽어 분석합니다. 그 밖에는 정보를 팔거나 광고에 쓰지 않고, 다른 사람이나 회사와 나누지 않습니다.

4. 저장과 삭제

인증 토큰과 통계 기록은 채널 주인의 PC에만 저장합니다. 이 도구는 따로 서버를 두지 않습니다. 인증 토큰은 접근 권한을 철회하거나 PC에서 토큰 파일을 지우면 쓸 수 없게 되고, 통계 기록은 채널 주인이 지울 때까지 PC에 남습니다.

5. 접근 권한 철회

언제든 Google 보안 설정의 서드 파티 액세스 페이지에서 이 도구의 접근 권한을 철회할 수 있습니다.

6. 쿠키와 광고

이 도구는 광고나 제3자 콘텐츠를 보여 주지 않습니다. 이 웹페이지는 GitHub Pages에 올려 두었으며, 쿠키나 방문 분석 도구를 쓰지 않습니다. 도구가 기기에 저장하는 것은 4번의 인증 토큰과 통계 기록뿐입니다.

7. Google 개인정보처리방침

이 도구는 YouTube API 서비스를 사용하므로 Google 개인정보처리방침도 함께 적용됩니다.

8. 문의

Privacy Policy (English)

Effective 2026-11-03

  • Who uses it: only the owner of the YouTube channel @n0wst4ndup, to upload their own videos and read their own channel's analytics. This tool uses YouTube API Services.
  • Data accessed: the OAuth token for the scopes the owner granted (youtube.upload, yt-analytics.readonly); the owner's video files with their titles, descriptions and tags; aggregate statistics of the owner's videos (views, engaged views, watch time, average percentage viewed, likes, comments, shares, subscribers gained and lost). It does not access other accounts or channels, comment text, or information that identifies individual viewers.
  • Use and sharing: used only to upload videos and to keep statistics records on the owner's computer for planning future videos. An AI tool the owner uses (Anthropic's Claude) reads these records to analyze them. Otherwise the data is not sold, not used for advertising, and not shared with anyone.
  • Storage and deletion: tokens and records are stored only on the owner's computer; there is no server. A token stops working when access is revoked or the token file is deleted. Records stay on the owner's computer until the owner deletes them.
  • Revoking access: at any time on the Google security settings page.
  • Cookies and ads: no ads or third-party content. This page is hosted on GitHub Pages and uses no cookies or analytics. The tool stores only the token and records described above on the device.
  • Google Privacy Policy: https://www.google.com/policies/privacy
  • Contact: questions or complaints about privacy can be left on GitHub Issues.
